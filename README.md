# WinGrid

**WinGrid** — утилита для автоматической расстановки окон на рабочем столе Windows.  
Вы задаёте список заголовков окон, выбираете монитор для каждого, а программа располагает их ровной сеткой с учётом панели задач и DPI.

## Возможности

- 🖥️ **Поддержка нескольких мониторов** – каждый заголовок можно привязать к любому монитору.
- 🔧 **Гибкая настройка** – размер окон и расстояние между ними настраиваются.
- 📐 **«Вплотную»** – окна слегка перекрываются, убирая зазоры между ними.
- 🎯 **Пользовательская геометрия** – для отдельных окон можно задать точный размер и позицию (через слайдеры, с live-предпросмотром).
- 📋 **Живая подсветка** – поля ввода заголовков подсвечиваются зелёным/красным в зависимости от того, найдено ли соответствующее окно.
- 🔄 **Сохранение конфигураций** – все настройки сохраняются в `.ini`-файл, который можно загружать и сохранять.
- 🌐 **Двуязычный интерфейс** – русский и английский, переключение по кнопке.
- 🖱️ **Draggable** – перемещение окна программы за любой фон (не только за заголовок).
- ⌨️ **CLI-режим** – сборка с суффиксом `CLI` в имени файла работает без GUI: загружает конфиг, расставляет окна и закрывается (полезно для автоматизации).
- 📊 **Просмотр мониторов** – команда `--list-monitors` выводит информацию о подключённых экранах.

## Использование

1. Запустите `WinGrid.exe`.
2. Введите заголовки окон (можно выбрать из списка открытых через кнопку `...`).
3. Назначьте каждому окну монитор (выпадающий список).
4. При необходимости включите «Окна вплотную» или «С учётом таскбара».
5. Нажмите **«Применить»**, чтобы расставить окна.
6. Сохраните настройки в `.ini`-файл через **«Сохранить настройки»**.

## Команды CLI

```bash
WinGrid.exe --config "путь\к\config.ini"   # загрузить конфиг и применить
WinGrid.exe --list-monitors                # вывести информацию о мониторах
